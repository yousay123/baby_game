# 蜜糖生活 · 3D

真·3D 网页游戏（Vite + Three.js）。旧版 2D 在 `_legacy_2d/`。

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

## 玩法流程

1. **化妆屋**：口红/腮红/眼影/发型/换装 → 化好妆去超市
2. **超市**：拿购物车 → 点货架购买 → 结账 → 出口回家（手提袋）
3. **客厅**：开关电视/灯/空调，进厨房或餐厅
4. **厨房**：放冰箱 → 取出 → 洗菜 → 开电器做饭 → **装盘/装碗** → 端去餐厅
5. **餐厅**：放到餐桌（热气）→ 喊爸妈吃饭 → 狗蹲桌下

## 调试

浏览器控制台：

- `HoneyLife3D.debugCook()` 直接生成热菜
- `HoneyLife3D.debugFillFridge()` 冰箱填充食材
